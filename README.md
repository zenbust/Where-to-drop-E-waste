# Where-to-drop-E-waste
IS Project

## Dependencies

This project requires the following Node.js packages:

1. **express**: A minimal and flexible Node.js web application framework.
2. **mongodb**: MongoDB driver for Node.js to connect and interact with your MongoDB database.
3. **dotenv**: A zero-dependency module that loads environment variables from a `.env` file.
4. **cors**: Middleware to enable Cross-Origin Resource Sharing.
5. **leaflet**: A JavaScript library for interactive maps.

## Installation

To install the necessary dependencies, navigate to the project root directory in your terminal and run:
